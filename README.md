# Software Developer Foundations — Learning Blueprint

A free, student-facing roadmap that guides a complete beginner from zero computer
experience to entry-level, job-ready software development, and onward toward
becoming a seasoned engineer.

This is **not** a learning platform — it's a guide. It tells the student what to
learn, why it matters, where to learn it for free, and how to prove they've
learned it, then points them to the wider world (books, courses, docs, GitHub
projects) to actually do the learning.

## Structure

The curriculum is organized into three top-level **levels**, selectable from
the sidebar level switcher in `index.html`:

- **Beginner** — the only level implemented so far. Covered in this codebase.
- **Intermediate** — planned. Coming soon.
- **Advanced** — planned. Coming soon.

The Beginner level is broken down into three **stages**, each made up of
numbered **tracks**:

- **Stage I — Computer Literate**: computer literacy, intro to programming
  concepts, the software development world, documentation.
- **Stage II — Learn to Program**: Pascal, Java, source control (Git/GitHub).
- **Stage III — Web & Beyond**: HTML + CSS, JavaScript, Python, Go.

At the end of each stage there's a shuffled assessment (50 questions drawn from
a larger question bank) with a 75% recommended pass mark before moving on.

Intermediate and Advanced are shown as disabled "Soon" pills in the level
switcher — the markup is in place, but their tracks and content don't exist
yet.

## Roadmap

The current content covers the **Beginner** level only. Planned next:

- **Intermediate**: DSA (taught in Java), design patterns, intro to Linux,
  and web programming with Flask, Go, Express.js and Django.
- **Advanced**: system architecture (monolith vs. microservices, etc.),
  Docker and containerization, plus further topics to be defined.
